Mission 3 Reflection

Mission 3 helped me understand the differences between AWS, Microsoft Azure, and Google Cloud. The cloud platform that impressed me the most was AWS because it provides a very large number of services and can support different types of applications. However, I also learned that Azure can be a better choice for organizations that already use Microsoft products, while Google Cloud has strong capabilities in artificial intelligence, machine learning, analytics, and Kubernetes.

AWS, Azure, and Google Cloud have many similarities. All three platforms provide virtual machines, storage, databases, networking, identity management, security, and other services needed to build cloud applications. They also have global infrastructure that allows organizations to run applications in different geographic locations. Although the services have different names, many of them perform similar functions.

Business requirements are important when selecting a cloud provider. A company should consider its budget, existing technologies, application requirements, security needs, scalability, and future plans. For example, Azure is a good choice for the university because it already uses Microsoft technologies. Google Cloud is suitable for the AI research company because of its AI and machine-learning capabilities. AWS is a good option for the startup and global e-commerce company because of its scalability and wide range of services.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider requires understanding the client's actual needs. I learned that there is no single cloud platform that is always the best for every organization. The best choice depends on the problem that needs to be solved.

My GitHub Cloud Computing Portfolio also improved during this mission. I learned how to organize research using Markdown files, compare cloud services, document Linux commands, and provide screenshots as evidence. This activity helped me become more familiar with cloud technologies and improved my understanding of how cloud solutions can be selected for real business situations.
